# ConsoleApp1


﻿Various files and project for a .NET 10.0 console application using C# 14.0 language features. 
This project demonstrates the use of modern C# syntax and features, including records, pattern matching, and async streams. 
The project structure includes a Program.cs file as the entry point, along with additional classes and methods to showcase different functionalities.

Main excercises in Exercises plus xUnit tests for each exercise in corresponding Test folder and files. 
The project is organized to facilitate learning and experimentation with C# 14.0 features in a .NET 10.0 environment.

Kattis folder contains prepartion tasks for Kattis programming challenges.
