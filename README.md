# ReEducation


﻿Various files and project for a .NET 10.0 console application using C# 14.0 language features. 
The projects demonstrates the use of modern C# syntax and features, including records, pattern matching, and async streams. 

Main excercises in Exercise folders plus xUnit tests for each exercise in corresponding Test folder and files. 
The project is organized to facilitate learning and experimentation with C# 14.0 features in a .NET 10.0 environment.

Kattis folder contains prepartion tasks for Kattis programming challenges.
