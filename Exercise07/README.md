# Exercise 07 - LINQ

A console app (`SolutionSetup`) that practices LINQ queries on a list of students.

## Topics covered

- **Where**: filter students by age.
- **Select**: project names only.
- **Count**: count students and students in class A.
- **Take**: get the first three students and the two highest scores.
- **Distinct**: list unique classes and ages.
- **Any / All**: check for a score of 100 and for a minimum score of 50.
- **FirstOrDefault / LastOrDefault / SingleOrDefault**: find students by class or Id.
- **GroupBy**: group students per class.
- **Sum / Average / Min / Max**: compute score statistics.

## Running the exercise

1. Open `Exercise07\SolutionSetup.slnx` in Visual Studio.
2. Set `SolutionSetup` as the startup project.
3. Press **F5** or **Ctrl+F5** to run.

## Requirements

- .NET 10 SDK
