I updated the workflow so it builds every exercise's DocFX site and publishes them together under one GitHub Pages site, with an index page linking to each one. The change is committed as 1b2dd9d, not pushed.
What changed
•	.github/workflows/docfx.yml:
•	Runs on changes under Exercise*/** and the index file.
•	Finds every Exercise*/*/docfx/docfx.json and builds each one.
•	Copies each result to site/<exercise>/, so Exercise09 is at /exercise09/.
•	Copies docs/site-index.html to site/index.html as the landing page and adds .nojekyll.
•	docs/site-index.html: the landing page, currently listing Exercise 09.
Adding a new exercise (for example, Exercise10)
1.	Copy Exercise09/SolutionSetup/docfx/ into the new project's folder, and update metadata.src and files in its docfx.json to point at the new .csproj.
2.	Add a link to docs/site-index.html: <li><a href="exercise10/">Exercise 10</a></li>.
The workflow picks up the new folder automatically.
