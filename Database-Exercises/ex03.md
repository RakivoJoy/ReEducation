1. Beskriv vad lastbalansering innebär (i allmänhet, behöver inte gälla just databaser)
Ett sätt att balansera trafik eller användning av resurser. Oftast nätverksresurser.

2. Ge ett konkret exempel på där lastbalansering kan vara bra att använda. 
För login-router-komponent som dirigerar trafik till olika databaser eller nätverksresurser beroende på mängden användare. Så att alla resurser har ungeför lika användning.

3. Anta att du bygger en hemsida. Vilka fördelar finns med använda lastbalansering? 
Ange tre fördelar
Du kan skapa flera databaser och komponenter som kan skalas bättre vid högre användning. Dessa kan användas till 80-90% var istället för maxas vid 100% användning och förlora prestanda.

4. Vad är SQL Server Replication?
Ett sätt att duplicera databaser med både skriv- och läsrättigheter.
Alla kopior är aktiva och alla har samma information.

5. Vad är Mirroring i SQL Server?
Ett sätt att ta 1 backup på databaser. Inga skriv/läsrättigeheter utan bara inaktiv kopia.

6. Vad är AlwaysOn Availability Groups i SQL Server

Ett  förbättrat Mirroring med läsrättigheter också. Kan ta flera kopior.
